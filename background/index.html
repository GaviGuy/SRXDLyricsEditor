Adding background colors via lyrics is a bit finnicky. If you're only using 1 backgrounded phrase, you can insert it as-is. If you wish to chain multiple backgrounded phrases together, there's more you should know.

When a lyric phrase becomes active, it will fade from partially visible to fully visible. Lyric phrases also fade out when they "exit", unless the next phrase cuts it off, in which case the game will remove it much quicker, sometimes instantly.

These effects combine to create brief moments where the background color disappears, which can cause annoying flashes of light or color. To prevent this, you can attack it from both sides:

Minimize the exit fade by cramming a lyric extension or dummy syllable (for example, "-") right into the next phrase
(you can literally stack lyric markers to get them as close as possible)

Minimize the entrance fade by stacking multiple background squares. This works because multiple partially-opaque symbols, when overlapped, create a more-opaque final product.
The "Extra Opaque Background" checkbox accomplishes this. Note: this extra opaque background is very ugly as it approaches, so only use it if there's already a backgrounded phrase on screen to hide its approach
(in other words, don't use it for the first backgrounded phrase of a sequence)
